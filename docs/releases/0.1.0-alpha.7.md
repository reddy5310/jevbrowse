## New for people
- **Bookmarks**: Ctrl+D adds or removes; Ctrl+Shift+O opens a searchable list; **import** the HTML file exported by Chrome, Edge, Firefox or Brave (web addresses only). Private sessions cannot add bookmarks.
- **Search engine choice**: DuckDuckGo (default), Google, Bing, Brave Search, Startpage, Ecosia (More menu, Bookmarks and search engine).
- **History** (Ctrl+H): search, Forget one entry, Clear all. Never records Private or agent sessions or pages classed Sensitive/Secret (banking, health).
- **Downloads list** (Ctrl+J): newest first, finished or not, **Show in folder**. Files are never opened from the list. A Private-session download is listed in memory only.
- **Per-site zoom** (Ctrl+ / Ctrl- / Ctrl+0): the familiar 25%..500% ladder, remembered by site, not remembered in Private/agent sessions or on Sensitive pages.
- **Links from other apps**: a link clicked elsewhere opens in the running JevBrowse (a new tab in the default workspace, never in a Private session); only http/https. **Make JevBrowse your default browser** registers it for the current user and opens Windows Settings; Windows requires you to choose it there. *Remove JevBrowse from the browser list* undoes the registration.

## New for developers
`scripts\dev.ps1 test|build|run|check`, a rewritten README and CONTRIBUTING (first change in ten minutes; how a change is checked), a feature-request template, and a release workflow (`.github/workflows/release.yml`: a tag builds and attaches the zip and checksums to a pre-release; a manual run keeps them as an artifact only). The manual run was verified on a hosted runner; the tag-publish step has not run yet.

## Verification (what was actually checked)
- Unit tests for each feature, including regressions that fail without the rule they protect. Mutation-checked: removing the scheme filter from bookmark import fails 2 tests (the first version of that test could not fail: it passed with the filter removed, and was strengthened); removing the class gate from the history recorder fails 2 tests.
- Real engine (`--additions-check`, 30 steps): a Private tab cannot bookmark; an ordinary page is in history and a Private page is not; an ordinary download is listed with its file present and a Private one is in memory only; zoom applies, is remembered per site, survives a reload and reset forgets it; Private zoom writes nothing.
- Two real processes (`external-link-check.ps1`, 6 checks): second start hands the link over and exits; a `javascript:` argument is ignored; a cold start with a link opens it.
- Default-browser registration: entries are current-user only; a real write/remove round-trip was run against a scratch registry key. **The real Windows default was not changed and the Settings hand-off was not clicked through.**

## Not verified / limits
- The new panels, the import file picker and the shortcuts were exercised through the same code paths, not by clicking each control; a clean-machine pass should click them.
- Zoom is page zoom applied by script (the WinUI web view does not expose the engine zoom): pages that size things in viewport units can differ.
- Not built: bookmark export, a bookmarks bar, download progress/cancel/retry, full-screen video (untested with the engine defaults), managed sign-in pop-ups (still unsupported).
- Still open and not code: signing certificate, update path, clean-Windows run, display scaling, high contrast, screen reader, the pixel-level no-flash screenshot observer.

## Data note
Database version is now **13** (bookmarks, history, downloads, site zoom). Data written by alpha.7 cannot be opened by alpha.4, alpha.5 or alpha.6: they refuse newer data and leave it untouched. Use separate data folders when switching.

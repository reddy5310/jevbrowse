## Build note (a real trap, fixed locally)
An incremental Release build reused a stale, mis-generated resource index (`JevBrowse.App.pri` at 22 KB instead of about 2.2 MB). The app then crashed at startup with `Cannot locate resource ... Microsoft.UI.Xaml/Themes/themeresources.xaml`, and the packaged smoke caught it (no window on any launch). Deleting `artifacts\obj\JevBrowse.App\release_win-x64` and `artifacts\bin\JevBrowse.App\release_win-x64` and rebuilding restored the 2.2 MB file and every launch check. If a release build ever shows no window, check that file's size first.

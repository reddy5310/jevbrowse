## Prerequisites

Windows 10 (19041+) or Windows 11, x64. The **Microsoft Edge WebView2 Runtime** (present on current Windows 11 and most updated Windows 10). What happens when it is
missing is **not yet tested**. No .NET install is needed (self-contained). Windows will show a SmartScreen warning because the build is unsigned.

## Install and data

Extract the ZIP anywhere and run `JevBrowse.App.exe`. There is no installer. Your data is in `%LOCALAPPDATA%\JevBrowse` (tabs and settings in `db\browser.db`, browser
profiles in `profiles\`). Private-session profiles are temporary and deleted when the session ends or the app closes.

**Backup:** close JevBrowse, then copy the whole `%LOCALAPPDATA%\JevBrowse` folder. To restore, close JevBrowse and copy it back. A build that finds data from a
NEWER version refuses to open it and leaves it untouched. Downloads go to your normal Downloads folder (also from a Private session).

## Verified on the packaged ZIP (`docs/releases/0.1.0-alpha.1-packaged-smoke.json`, 15 checks + 36 recovery checks, all passing)

Checksum matches; contains `BUILD.json` with this commit; no symbols or dev files inside; first launch shows the welcome page and the first-run tips; first-run is
remembered; the second launch has no tips and the saved tab is back; a launch with WebView2 pointed at a dead proxy starts and stays up; a crashed app leaves no
readable Private data and the next start sweeps it; a normal close deletes the Private profile; a damaged database is set aside and the app starts; a database from a
newer version is refused untouched; closing the window with a live agent takes about a second and leaves nothing.
Development-only setting used: `JEVBROWSE_DATA_DIR` (data kept off C: on the dev machine).

## Not verified (needs a clean account or VM)

Missing WebView2 runtime; genuinely offline first launch; the default data location; SmartScreen behaviour; downloads and uploads; sign-in persistence across restarts
on a real account; meetings; long sessions; display scaling above 100%, high contrast, a real screen reader; a second machine.

## Known limitations

Unsigned, portable only, no updater. Pop-ups from sign-in flows that need `window.opener` open as ordinary tabs and cannot report back. Private-session downloads land
in the ordinary Downloads folder. Screenshot (agent) is experimental, off by default, and its "never visible even briefly" claim is unproven. The agent endpoint is off
unless the person turns it on. A power cut can lose the last few saved changes. First launch with no network starts without Shield's filter lists until they download.
